Pin specific responses with YAML and CEL rules.

Need deterministic responses or error states for tests? Write declarative stubs that match request fields with Common Expression Language (active_if), compute dynamic fields, or simulate gRPC error codes.

Proxy live services, record stubs, or load schemas from anywhere.

Place FauxRPC in front of an upstream service with --proxy-to to inspect calls, inject stubbed test scenarios, record real responses with --record-dir, and automatically fake UNIMPLEMENTED endpoints. Or start standalone from local .proto files, BSR modules, server reflection, and OpenAPI specs.

$ fauxrpc run --proxy-to=127.0.0.1:8080 --record-dir=stubs/ --dashboard
